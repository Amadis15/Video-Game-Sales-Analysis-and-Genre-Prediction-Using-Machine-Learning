This project employs machine learning to predict a game's genre based on its features and examines video game sales data to identify important trends. Visualizations were made to address business-driven queries like which genres were most popular in each decade and how sales differed by region after the dataset had been cleaned and examined. Bar plots and heatmaps are used in the analysis to provide insights into global gaming trends. After that, a Random Forest and Decision Tree classifier were trained to predict game genres; the Random Forest model demonstrated better accuracy and generalization. Data preprocessing, exploratory data analysis, visualization, and machine learning with Python, Pandas, Seaborn, and Scikit-learn are all demonstrated in this project.
